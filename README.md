# Fantasy Football ML/AI — Claude Code Autonomous Build Package

This directory is the definitive implementation package for the Fantasy Football ML/AI project.

## Files
- `PRODUCT_SPEC.md` — definitive product requirements
- `ARCHITECTURE.md` — technical/system architecture
- `IMPLEMENTATION_PLAN.md` — autonomous build sequence
- `ACCEPTANCE_CRITERIA.md` — definition of done
- `AGENT_CONTRACTS.md` — agent responsibilities and structured schemas
- `CLAUDE_CODE_LEAD_PROMPT.md` — paste as the initial Claude Code lead instruction
- `CLAUDE.md` — durable project instructions

## Original documents
If the original v1 documents are also copied into the project, preserve them. They remain authoritative source material. The consolidated package resolves implementation-workflow conflicts in favor of autonomous Claude Code execution while preserving product requirements.

## Recommended startup
1. Put this package into the repository.
2. Give Claude Code the lead prompt.
3. Tell Claude Code to start.
4. Let it inspect, plan, implement, test, fix, and continue autonomously.

The lead prompt intentionally does not duplicate every product requirement; it references the project documentation and supplies the operating rules for autonomous implementation.
